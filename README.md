# Sprint_6
Финальный проект 6 спринта
Автотесты на selenium для учебного сервиса «Яндекс.Самокат».

Основа для написания автотестов — фреймворк pytest.
Установить зависимости — pip install -r requirements.txt.
Команда для запуска — pytest -v.

Папка tests содержит тесты на:
1) test_order - позитивный сценарий заказа самоката от нажатия на кнопку "Заказать" до подтверждения заказа,
2) test_FAQ - соответствие вопросов и ответов в разделе "Вопросы о важном".

Папка locators содержит базовые локаторы, локаторы для раздела вопросов и ответов, локаторы для элементов на странице заказа.
Папка pages содержит базовые методы, методы для раздела вопросов и ответов, методы для страницы заказа.
Папка helpers содержит методы генерации тестовых данных и адреса проверяемых страниц.
Папка allure_results содержит сгенерированные отчёты Allure.
